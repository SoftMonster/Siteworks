🟢 Site Works 1.6.8 · R2 Hotfix 18

Build lineage: 1.6.8 / R2 HF18 ← 1.6.7 / R2 HF17

  • 🌐 Standardises webdata (Steam webpage data) and filedata (Site Works saved inventory).
  • 🔄 Replaces separate current-data and full-scan actions with one Synchronise inventory operation.
  • 🧾 Adds a versioned IndexedDB journal of changed/new serialisable asset and description records, appended as Steam streams batches.
  • 🧱 Consolidates the saved design catalogue and inventory holdings into one versioned filedata record; existing records migrate automatically.
  • 🔁 Adds a journal replay function to rebuild filedata after future reconciliation changes.
  • 💷 Price capture remains a separate enrichment operation; Inventory list is read-only.
  • 📚 Adds docs/WEBDATA_FILEDATA_ARCHITECTURE.md with assumptions, dependencies, diagnostics and future Steam-update maintenance steps.
  • 🧪 Automated checks do not substitute for live Brave/Steam acceptance testing.

🟢 Site Works 1.6.8 · R2 Hotfix 18

Build lineage: 1.6.8 / R2 HF18 ← 1.6.6 / R2 HF16

  • 🧠 Makes Steam's cumulative in-memory inventory cache the preferred source for inventory discovery and holdings.
  • 🔄 Uses Steam's native LoadMoreAssets() loader when runtime feature detection confirms the required capabilities; Steam controls its own request size, continuation and delay.
  • 📦 Adds Load cached inventory data, which reads already-loaded cache data without starting inventory requests or navigating.
  • 🧮 Distinguishes asset entries, unique designs, reusable descriptions and aggregated item quantities, including stack amounts.
  • 🧭 Requires Steam's own completion flag and final description validation before saving a complete inventory snapshot.
  • 🛑 Stop preserves partial cache data and does not cancel or interfere with a Steam request already in progress.
  • 🧩 Uses runtime capability detection rather than a hard-coded Steam version; the previous verified DOM scanner remains a fallback.
  • 📚 Adds the Steam inventory cache integration handover and future website-update maintenance guide in docs/STEAM_INVENTORY_CACHE_INTEGRATION.md.
  • 🧪 Automated validation is not live Brave/Steam acceptance testing. The native-cache scan still requires controlled live testing.
